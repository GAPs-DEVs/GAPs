# Guitar Practice API

Google 로그인, 파싱된 악보 업로드, 개인 악보함 목록·버전 조회를 제공하는 Django API입니다.

프론트·PySide 앱 담당자는 [클라이언트 연동 가이드](../docs/api/README.md#client-guide)부터 확인하세요.
인증 흐름, 요청·응답 예시, 필드 제약, 오류 처리, 현재 구현 범위를 정리했습니다.

- [Postman으로 요청 확인](../docs/api/README.md#postman)
- [서버 설정 및 실행](../docs/api/README.md#setup)

상세 문서는 위 통합 README 한 곳에서 관리합니다.
